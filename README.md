# SimpleTab 简页 v1.4.0

无广告、简洁的浏览器起始页（新标签页）扩展：时钟、搜索、快捷链接、文件夹、拓展坞，一应俱全。支持毛玻璃与 Fluent 2 双风格一键切换、静态图 / 视频壁纸、3D 动效（搜索框沉入、磁贴落位、文件夹翻转）、一键外观预设。

- 版本：v1.4.0
- 类型：Chrome / Edge 扩展（Manifest V3）
- 作者：史宇辰

---

## 一、安装方法（Chrome / Edge 通用）

> 说明：MV3 扩展不能直接双击 `.zip` 安装，需要先**解压成文件夹**，再通过「加载已解压的扩展程序」加载。本包 `simpletab-v1.4.0.zip` 内的 `manifest.json` 位于压缩包根目录。

### 方式一：从压缩包安装（推荐给普通用户）

1. **解压** `simpletab-v1.4.0.zip` 到一个固定目录（解压后请**不要移动或删除**该文件夹，否则扩展会失效），确认目录下能看到 `manifest.json` 和 `index.html`。
2. **打开扩展管理页**，二选一：
   - Chrome：地址栏输入 `chrome://extensions` 回车
   - Edge：地址栏输入 `edge://extensions` 回车
3. 打开左下角**「开发者模式」**开关。
4. 点击右上角**「加载已解压的扩展程序」**，选择刚才解压出来的文件夹。
5. 加载成功后，新建标签页（或按 `Ctrl+T`）即可看到 SimpleTab 简页。

## 二、常用操作

| 操作 | 说明 |
|------|------|
| 搜索 | 主页搜索框直接输入回车；点胶囊切换搜索引擎，`Tab` 键循环切换 |
| 快捷链接 | 点顶部齿轮 → 链接页；点「+」添加；右键磁贴可编辑 / 删除 / 移入文件夹 / 加入拓展坞 |
| 文件夹 | 点齿轮拖入链接区创建；磁贴间拖拽排序；拖回齿轮删除 |
| 壁纸 | 默认「极光」渐变壁纸；齿轮 → 壁纸偏好可上传图片或视频（图片原图直存，视频静音循环播放）或移除 |
| 外观 | 齿轮 → 常规设置：外观预设（纯净 / 质感 / 现代 / 灵动）/ 主题 / 风格（毛玻璃 / Fluent 2）/ 动画 / 主题色 / 时钟 / 磁贴密度等全部可调 |

## 三、数据说明

- 设置数据存储在浏览器本地（`chrome.storage.local`）。云端备份为**手动快照**（`chrome.storage.sync`，跟随浏览器账号）：配置改动只存本机，「立即同步」把当前状态保存为云端快照，「从云端恢复」回到该快照。
- 壁纸存于浏览器 IndexedDB，原图直存（4K 以内不压缩、不随设置打包），不占用本地配额、不上云。
- 链接图标存于浏览器本地缓存，重复打开新标签页不再重新加载，秒开无闪烁。
- 卸载扩展会删除本地数据；云端快照跟随浏览器账号保留，重装后可用「从云端恢复」找回。

## 四、常见问题

**Q：加载后新标签页没变？**
检查是否加载了正确的文件夹（应包含 `manifest.json`），并在扩展管理页确认该扩展处于「已启用」状态。

**Q：提示「无法加载清单文件」？**
解压目录层级不对。请确认直接选中的文件夹**第一层**就是 `manifest.json`，不要多套一层文件夹。

**Q：想在新窗口也生效？**
起始页只接管浏览器新标签页；另开窗口的新标签页同样生效（新开标签页即新标签页）。
