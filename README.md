## 一、安装方法（Edge / Chrome 通用）

> MV3 扩展不能直接双击 `.zip` 安装，需先**解压成文件夹**，再「加载已解压的扩展程序」。本包 `simpletab-v1.4.0.zip` 内 `manifest.json` 位于压缩包根目录。

### 方式一：从压缩包安装（推荐）

1. **解压** `simpletab-v1.4.0.zip` 到固定目录（解压后**不要移动或删除**该文件夹，否则扩展失效），确认第一层能看到 `manifest.json` 与 `index.html`。
2. 打开扩展管理页：Edge 输入 `edge://extensions`，Chrome 输入 `chrome://extensions`。
3. 打开右下角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择解压出的文件夹。
5. 新建标签页（`Ctrl+T`）即可看到 SimpleTab。

### 方式二：开发者模式直接加载源码构建

```bash
npm install
npm run build    # 产物在 dist/
```

然后在扩展管理页「加载已解压的扩展程序」选择 `dist/` 目录。

## 三、数据说明

- 设置数据存于浏览器本地（`chrome.storage.local`）。云端备份为**手动快照**（`chrome.storage.sync`，跟随账号）：配置改动只存本机，「立即同步」保存云端快照，「从云端恢复」回到该快照。
- 壁纸存于 IndexedDB（图片原图直存、4K 内不压缩），不上云、不随配置打包。
- 链接图标存于本地缓存，重复打开新标签页秒开无闪烁。
- 卸载扩展会删除本地数据；云端快照跟随账号保留，重装后可用「从云端恢复」找回。

## 四、常见问题

**Q：加载后新标签页没变？**
检查选中的是否是正确的文件夹（第一层含 `manifest.json`），并在扩展管理页确认该扩展「已启用」。

**Q：提示「无法加载清单文件」？**
解压层级不对。直接选中**第一层就是 `manifest.json`** 的那个文件夹，不要多套一层。

**Q：想在新窗口也生效？**
起始页接管所有新标签页，新开窗口的新标签页同样生效。

**Q：如何同步到另一台设备？**
两端登录同一浏览器账号 → 本机「立即同步」→ 另一台「从云端恢复」。
