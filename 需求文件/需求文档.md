# 浏览器起始页插件 — 需求文档（PRD）

- 版本：v1.1
- 目标浏览器：Microsoft Edge（Chromium），兼容 Chrome
- 技术栈：Vue 3 + Vite + Manifest V3
- 更新记录：
  - v1.1 补充页面交互细节（搜索栏动画 / 右键进入快捷链接页 / 文件夹分组 / 设置下拉 / 常规设置 / 壁纸偏好）

---

## 1. 项目概述

一个浏览器新标签页起始页插件，安装后每次打开新标签页即显示本页。

核心诉求：**简洁、美观、本地化**——所有数据存本地，无需账号、无后端、离线可用。

设计风格：**毛玻璃质感（Glassmorphism）+ 可选本地壁纸 + 深色/浅色主题**。

---

## 2. 页面架构与交互流程

```
主页（默认仅搜索栏）
  ├─ 搜索栏 hover → 拓宽动画
  ├─ 搜索区外 鼠标右键 → 进入快捷链接页（模糊背景 + 放大动画）
  └─ 快捷链接页
       ├─ 时钟保留、搜索栏隐藏
       ├─ 右上角：设置图标（hover 旋转 → 点击下拉菜单）
       │     ├─ 常规设置
       │     ├─ 壁纸偏好
       │     └─ 关于
       ├─ 设置图标可拖拽 → 变为文件夹（收纳链接分组）
       ├─ 快捷链接：加号上拉框添加 / 右键编辑 / 删除二次确认
       └─ 返回主页：ESC 或点击页面空白
```

## 3. 功能需求

### 3.1 主页搜索栏（默认短小 + hover 拓宽动画）

| 需求 | 说明 |
|---|---|
| 默认形态 | 主页打开**仅显示搜索栏**，默认短小居中 |
| 拓宽动画 | 鼠标移入后横向拓宽，带平滑动画效果（transform 实现，避免重排） |
| 多引擎 | 内置百度 / Bing / 谷歌 / 必应，URL 模板携带关键词 |
| 引擎切换 | 键盘 **Tab 键**循环切换，输入框下方当前引擎小标签高亮 |
| 回车搜索 | 按 Enter 跳转当前引擎搜索结果页 |
| 状态记忆 | 当前引擎写入本地存储，下次打开保持 |

### 3.2 快捷链接页（右键进入 + 动画）

| 需求 | 说明 |
|---|---|
| 进入方式 | 主页搜索区外**鼠标右键**进入快捷链接页 |
| 进入动画 | 背景产生**模糊 + 放大**动画效果 |
| 页面状态 | **时钟保持不变**、搜索栏隐藏 |
| 默认视图 | 显示添加入口：空图标上带**加号**样式 |
| 返回主页 | **ESC** 或点击页面**空白区域** |
| 链接数量 | **不限**，超出区域可滚动 |

### 3.3 快捷链接增删改

| 需求 | 说明 |
|---|---|
| 添加 | 点击加号图标，从图标处**向上弹出**添加上拉框 |
| 添加字段 | ① 标题（默认"添加网站"）② 网址（文本输入，可直接粘贴）③ 标题（按粘贴网址自动分析名称，可手动改）④ 图标（自动获取，获取不到用**文字图标**，文字取自标题） |
| URL 校验 | 缺 `http(s)://` 自动补全，非法地址阻止并提示 |
| 编辑 | 页面内右键图标可**编辑 / 删除**，编辑字段与添加字段一致 |
| 删除 | 需**弹窗二次确认** |
| 排序 | 鼠标拖拽排序，顺序持久化 |
| 图标 | 自动抓取网站 favicon，失败降级首字文字图标 |

### 3.4 设置图标 + 文件夹分组

| 需求 | 说明 |
|---|---|
| 位置 | 快捷链接页**右上角** |
| hover 效果 | 图标鼠标移入有**旋转 + hover** 效果 |
| 下拉菜单 | 点击展开，含三项：**常规设置 / 壁纸偏好 / 关于** |
| 拖拽成文件夹 | 图标可拖拽**变为文件夹**形态，用于**收纳快捷链接做分组** |
| 文件夹操作 | 点击文件夹可**修改标题**；支持展开 / 收起；可再次拖回恢复为设置图标 |
| 分组数据 | 链接归属分组关系持久化，分组顺序可排序 |

### 3.5 关于页

| 需求 | 说明 |
|---|---|
| 内容 | 作者：**史宇辰**（其余后续补充） |

### 3.6 常规设置页

| 分类 | 需求 | 说明 |
|---|---|---|
| 时钟 | 12 / 24 小时制 | 切换即时生效并记忆 |
| 时钟 | 是否显示秒 | 开关 |
| 时钟 | 时间分隔符是否闪烁 | 冒号闪烁开关 |
| 时钟 | 单独修改时钟字体 | 内置 3~4 种系统字体（现代无衬线 / 等宽数字 / 衬线等） |
| 主题 | 主题色切换 | **亮色 / 黑暗 / 跟随系统**三选一，跟随系统实时响应 |

### 3.7 壁纸偏好页

| 需求 | 说明 |
|---|---|
| 展现 | 打开为**动态弹窗**，标题「壁纸自定义」 |
| 选图 | 点击「选择壁纸」按钮选取本地图片，支持主流图片格式 |
| 预览 | 弹窗内**缩略图**实时显示壁纸效果 |
| 介绍 | 文案：**将您喜爱的图片作为壁纸** |
| 压缩存储 | Canvas 压缩（上限约 1920px / WebP）后以 dataURL 存本地 |
| 移除 | 提供「移除壁纸 / 恢复默认」入口 |

### 3.8 毛玻璃与壁纸自适应（全局）

| 需求 | 说明 |
|---|---|
| 自适应 | `cover` 铺满，任意比例不变形 |
| 毛玻璃 | 主内容容器 `backdrop-filter: blur` 半透明，保证文字可读 |
| 降级 | 不支持 `backdrop-filter` 时降级纯半透明背景 |
| 默认背景 | 未设置壁纸时显示内置渐变背景兜底 |

## 5. 技术选型

| 项 | 选型 | 说明 |
|---|---|---|
| 框架 | Vue 3（Composition API）+ Vite | 单页无路由，构建产物作插件根目录 |
| 清单 | Manifest V3 | Edge/Chrome 现行标准 |
| 存储 | `chrome.storage.local` + `unlimitedStorage` | 离线可用，存壁纸 base64 |
| 图标 | `chrome://favicon`（`favicon` 权限），兜底 Google s2 / 文字图标 | 本地方案免跨域 |
| 壁纸 | FileReader → Canvas → WebP → dataURL | 全本地不上传 |
| 毛玻璃 | CSS `backdrop-filter` + CSS 变量 | 原生支持，零依赖 |

```
│   ├── App.vue

│   │   ├── ClockView.vue  # 时钟（12/24、秒、分隔符闪烁、字体）
│   │   ├── SettingsIcon.vue # 右上角设置图标（hover/旋转/下拉/拖拽成文件夹）

├── public/
│   └── icons/             # 16/32/48/128 插件图标
└── vite.config.js
```

## 7. 异常处理

| 场景 | 处理 |
|---|---|
| 站点无 favicon | 文字图标兜底（取标题首字） |
| 粘贴 URL 非法 / 缺协议 | 自动补全 `https://`，仍非法则阻止并提示 |
| 壁纸文件过大 / 格式不支持 | 拒绝并提示，支持主流图片格式 |
| 旧浏览器无 backdrop-filter | `@supports` 降级半透明 |
| 存储写入失败 / 超限 | 提示并保留内存态，不阻塞使用 |
| 删除链接 / 文件夹 | 二次确认，确认后同步清理分组关系 |

## 8. 验收标准

1. 安装后新标签页自动显示本页，主页默认仅短小搜索栏，hover 拓宽动画流畅。
2. 搜索区外右键进入快捷链接页，模糊+放大动画生效；时钟保留、搜索栏隐藏；ESC / 点空白返回。
3. Tab 键循环切换 ≥4 搜索引擎，高亮正确，记忆生效。
4. 快捷链接：加号上拉框添加、URL 自动补全校验、标题自动分析、图标兜底、右键编辑、删除二次确认、拖拽排序全部可用，刷新后保留。
5. 设置图标 hover 旋转、点击下拉三项菜单；拖拽成文件夹收纳链接、改标题、展开收起正常。
6. 常规设置：时钟 12/24、显示秒、分隔符闪烁、字体切换均即时生效并记忆；亮色/黑暗/跟随系统切换正确。
7. 壁纸偏好：动态弹窗、选本地图、缩略图预览、压缩存储、移除恢复默认均正常。
8. 无壁纸时显示默认渐变；全程无网络依赖离线可用；无控制台报错。
