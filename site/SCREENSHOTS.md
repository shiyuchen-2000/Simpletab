# SimpleTab 宣传页 · 截图指南

> 网页需要的 7 张图片，全部由你本地截图生成（不向 AI 传输图片）。
> 流程：**启动扩展 → 逐个界面截图 → 按命名放入 `site/assets/shots/` → 通知接入 HTML**。

---

## 0. 准备

```bash
cd "D:\01MyProject\个人起始页"
npm run dev
```

用 **Edge** 打开终端提示的地址（默认 `http://localhost:5173`）。
这是扩展的开发版，普通浏览器即可运行，设置会存入浏览器本地。

> 若端口被占用，请使用终端显示的实际端口。

## 2. 截图方式（二选一）

### 方式 A · 精确尺寸（推荐）

1. `F12` 打开 DevTools
2. `Ctrl + Shift + M` 进入设备模拟
3. 顶部尺寸填：
   - `hero.png` → `880 × 480`
   - `feature-*.png` → `700 × 440`
4. 右上 `⋮` → **Capture screenshot**（捕获屏幕截图）

### 方式 B · 快速框选

`Win + Shift + S` 直接框选保存。
尺寸差一点没关系，HTML 会以 `object-fit: cover` 自动铺满裁切。

## 4. 接入页面

`site/index.html` 中 7 个虚线占位框需替换为 `<img>` 引用才能显示图片。
**图片放好后，联系我一次性替换**（缺图时仍保留占位提示，不会报错）。

---

## 注意事项

- **不要截浏览器外框**：只截界面内容，避开地址栏、标签栏。
- **明暗主题**：扩展默认暗色极光，与页面亮色会有对比。想协调，可在扩展里切换亮色（齿轮 → 常规设置 → 外观 → 亮色）后再截。
- **应急方案**：可用已有宣传页（`store-promo-1400x560.html`、`store-promo-settings.html`、`store-screenshots/edge-frame.html`）导出 PNG 应急。
